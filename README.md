# Treasure Run

2D Mobilegame-Projekt, entwickelt mit Godot 4 (GDScript).

## Spielprinzip

Springe von Plattform zu Plattform, sammle die Kisten ein und töte alle Gegner. Sobald du den Schlüssel hast und alle Gegner besiegt sind, öffnet sich die Ausgangstür.

## Steuerung

| Aktion | Tastatur | Mobile |
|---|---|---|
| Bewegen | A / D oder Pfeiltasten | Touch-Buttons links |
| Springen | W / Pfeil hoch / Space | Button rechts oben |
| Schiessen | F | Button rechts unten |

## Starten

Projekt in Godot 4 öffnen (`app/project.godot`) und auf Play drücken.

## Assets

Tiles und Sprites aus dem [Kenney Simplified Platformer Pack](https://kenney.nl/assets/simplified-platformer-pack) (CC0).
